# 05 身份证明文件待提供清单

官网[所需文件](https://www.ccopyright.com.cn/index.php?optionid=1080)按申请主体类型要求身份证明原件照片或扫描件；问题问答页面还说明外文材料有译文、公证/认证等要求。以下只列用户需自行准备的类别，不收集、不复制、不伪造证件。

| 申请主体 | 用户自行准备 | 状态 |
| --- | --- | --- |
| 中国自然人 | 按官网当前表单要求准备本人有效身份证明原件照片/扫描件 | **需用户提供** |
| 中国企业法人/其他机构 | 统一社会信用代码营业执照或相应登记/证书原件照片/扫描件，以及表单要求的其他主体信息 | **需用户提供** |
| 其他主体 | 按官网对事业单位、机关、社会组织或外国主体的对应要求准备证明；外国主体可能需要附加证明书/使领馆认证、公证及译文 | **需用户确认并提供** |
| 代理办理 | 代理人和代理权限/期限等材料，按官网当前表单填写 | **需用户提供；本包不代办** |

不要把身份证号、住址、营业执照、签名、印章或证件扫描放进仓库或源程序/文档鉴别材料。具体主体材料以用户在官网当前页面看到的要求为准。
