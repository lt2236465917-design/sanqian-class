## 申请表/附件草稿

建议在“软件作品说明”中如实选择“修改”并说明：三千上课是在 Apache-2.0 上游项目基础上进行的个人课表、导入复核、日历/提醒、小组件、跨平台品牌和平台适配等修改；具体修改范围由申请人按 Git 历史和实际贡献复核。可参考 `git log --oneline`，但提交时不把 Git 提交记录当作官网要求或权利证明。

随材料保留：

1. 根目录 `LICENSE` 的完整副本（Apache-2.0）；
2. 上游 URL 和访问日期；
3. 当前项目 About 页面关于上游修改和 Apache-2.0 的说明；
4. 用户确认后的修改说明；
5. 原权利人许可证明原件照片/扫描件（如官网对修改他人软件的要求适用）。

不能把 Apache-2.0 许可证写成“已经取得原权利人单独书面授权”，也不能把当前 GitHub 账户或远程仓库写成原权利人。官网[所需文件](https://www.ccopyright.com.cn/index.php?optionid=1080)和[填表说明](https://www.ccopyright.com.cn/index.php?optionid=1081)都提示修改他人软件需提交原软件著作权人的许可证明原件照片或扫描件。

用户需要自行：

- 核实上游软件的原著作权人及当前许可证是否足以覆盖本次登记场景；
- 联系有权主体并取得、保存可用于申请的许可证明（如需要）；
