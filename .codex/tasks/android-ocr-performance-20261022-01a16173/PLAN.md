# Android 本地 OCR 性能优化

## 目标
在当前指定三张真实课表截图上建立本地 Android OCR 基准，隔离实现候选，测量端到端阶段耗时、PSS、准确率/框及 APK 体积，尝试不损精度的性能优化，并交付不可发布候选 APK 和脱敏证据。

## 里程碑
1. 读取规则、检查并保护现有 Git 现场、核实精确样本位置及此前替换任务产物。
2. 建立三图人工标准答案和当前代码/包模拟器基线。
3. 隔离实现可复用引擎等候选，执行同图回归、资源/包体测量。
4. 独立审查证据并交付，说明模拟器与真机验证边界及数据清理。

## 约束
仅本机和任务专属模拟器处理原图；不上传、不调用云端/付费 API；不改备案、网页、真机；不提交推送发布；保护工作区未提交变更、正式旧包及用户文件。样本映射和原图 SHA-256 受限保存，公开报告脱敏。任何准确率回退均不通过。
